# Count pages

`ozaru.page_count` returns the number of pages as an `int`.

That's useful when you need to decide what to do with a document before you
process it:

```python
--8<-- "docs_src/page_count.py"
```

Output:

```text
--8<-- "docs_src/page_count.out"
```
